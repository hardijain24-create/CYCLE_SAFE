# CycleSafe Privacy Summary

**Disclaimer**: Real deployment requires legal review to ensure full compliance with laws such as GDPR, India DPDP Act, HIPAA, and other applicable regional privacy regulations.

## Consent
- User consent is actively obtained prior to processing data.
- We outline the specific purposes for data collection (e.g. tracking, forecasting).
- Users can withdraw consent at any time.

## Purpose Limitation
- Data is processed strictly for the consented purposes.
- Minimised data collection: only necessary attributes are gathered.
- No advertising or third-party analytics SDKs are used. All processing happens in this application only.

## Right to Erasure
- Users can completely delete all stored data via the privacy engine.
- After deletion, all files and records related to the user are permanently removed.

## Data Export
- Users have the right to request all data the application holds on them, which will be provided in a standard format (JSON).
